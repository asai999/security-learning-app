# security-learning-app
1. 概要

FastAPIとSQLiteを用いて、4択形式のセキュリティ演習問題を解けるWebアプリを開発することを通して各フレームワークを学習。

2. 使用技術

Python / FastAPI / SQLite / HTML / CSS / JavaScript

3. 実装した機能
- GETによる問題取得
- POSTによる回答送信と採点
- SQLiteへの回答履歴の保存
- HTML/JavaScriptによる問題演習画面

4. システム構成

ブラウザ → FastAPI → SQLite の関係を簡単な図で示す。

5. 学んだこと

HTTP通信、REST APIの基礎、SQL、データベース設計、フロントエンドとバックエンドの連携。
